# YOLOv8-object-detection-streamlit-app
# 🎯 VisionAI — Object Detection (YOLOv8 + Streamlit)

A real-time object detection web application built using YOLOv8 and Streamlit. Users can upload images and get instant predictions with bounding boxes, labels, and confidence scores.

## 🚀 Features
- Real-time object detection using YOLOv8
- Interactive UI with Streamlit
- Bounding box visualization with labels
- Confidence score display
- Optimized for CPU inference

## 🛠️ Tech Stack
- Python
- YOLOv8 (Ultralytics)
- Streamlit
- NumPy
- Pillow (PIL)

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
